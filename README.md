# 하루, 빌려드립니다

가천대 캠퍼스에서 생길 법한 일들을 골라보며 나를 알아가는 인터랙티브 자기소개 사이트입니다.

**[사이트 체험하기](https://gijun8850-hub.github.io/borrow-my-day/)**

## 체험 방식

한 번에 다섯 장면을 만납니다. 각 상황에서 방문자가 선택하면 본인의 행동과 속마음을 보여줍니다. 마지막에는 실제로 고른 답과 본인의 답변을 나란히 비교합니다.

상황은 가상이며, 행동과 속마음은 본인이 직접 답한 내용을 다듬었습니다. 다른 선택지들은 체험을 위한 가상 대안입니다. 실제 일화나 시간표, 실제 버스 정보를 재현하지 않습니다.

## 주요 기능

- 다섯 시간대에서 한 장면씩 고르는 하루 체험
- 전체 19개 상황과 챕터별 탐색
- 남은 시간, 화난 정도, 내용을 아는지에 따른 상황 변경
- 행동이 먼저 나오고 속마음이 펼쳐지는 화면
- 방문자가 선택한 상황에 대한 같은 선택·다른 선택 비교
- 브라우저에서 본 장면을 기억하고 새 장면을 우선 추천

공강의 잠과 휴대전화 사용처럼 본인 답변에 여러 행동이 포함되면 둘 다 비교에 반영합니다. 속마음이 없는 답변과 아직 답하지 않은 속마음을 구분합니다. 방문자의 속마음이나 성격은 추측하지 않습니다.

## 실행

루트의 `index.html`을 브라우저로 열면 별도 설치 없이 작동합니다. GitHub Pages는 `main` 브랜치의 루트 파일을 공개합니다.

수정 가능한 소스는 `dist/`에 있습니다. 로컬에서는 다음과 같이 실행할 수 있습니다.

```text
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 모든 소스를 포함한 배포용 단일 파일 |
| `dist/content.js` | 19개 상황과 선택지, 본인 답변 |
| `dist/story.js` | 하루 구성과 선택 처리 |
| `dist/details.js` | 상황별 연출과 방문자 비교 |
| `dist/app.js` | 화면과 이동 흐름 |
| `dist/styles.css` | 화면 디자인과 모바일 배치 |
| `tests/` | 상황 조건, 비교, 체험 흐름 검사 |

소스를 바꾼 뒤에는 루트의 단일 `index.html`에도 변경을 반영해야 합니다.

## 검사

```text
node --test tests/story.test.cjs tests/expansion.test.cjs tests/details.test.cjs
node --check dist/app.js
```

## 데이터

서버나 분석 도구로 방문자 답변을 보내지 않습니다. 브라우저의 localStorage에 본 장면 ID만 기록하며, 장면 모음에서 초기화할 수 있습니다. 저장이 제한된 환경에서도 체험은 작동합니다.

원본 인터뷰 메모와 작업용 파일은 저장소에 포함하지 않습니다.
